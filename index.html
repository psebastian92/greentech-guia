Instalación en Raspberry Pi
Instalás las herramientas necesarias una sola vez. Después de esto, el robot puede correr en cualquier momento.
1

Actualizá el sistema

Antes de instalar cualquier cosa, es buena práctica asegurarse de que el sistema esté al día.

bash
sudo apt update && sudo apt upgrade -y
2

Instalá Python y pip

Raspberry Pi OS ya trae Python 3. Verificá que esté instalado:

bash
python3 --version
pip3 --version

Si pip no está, instalalo con:

bash
sudo apt install python3-pip -y
3

Instalá ffmpeg

Necesario para que pydub pueda procesar y acelerar el audio.

bash
sudo apt install ffmpeg -y
4

Instalá las librerías Python

Todas las dependencias del proyecto de una sola vez:

bash
pip3 install groq gtts pygame sounddevice numpy scipy pydub --break-system-packages
ℹ️ El flag --break-system-packages es necesario en Raspberry Pi OS moderno. No rompe nada — solo le dice a pip que puede instalar aunque el sistema sea "administrado".
5

Creá la carpeta del proyecto y copiá el script

bash
mkdir ~/greentech
cd ~/greentech

Copiá el archivo greentech_voz.py en esa carpeta (por pendrive, SCP, o GitHub).

6

Verificá el micrófono

Conectá el micrófono USB y comprobá que el sistema lo reconoce:

bash
arecord -l

Deberías ver tu micrófono listado como un dispositivo de captura.

💡 Si tenés varios dispositivos de audio, podés identificar el número de tu micrófono con python3 -c "import sounddevice as sd; print(sd.query_devices())" y configurarlo en el script con el parámetro device=N.
Conseguir y configurar la API Key de Groq
Groq es el servicio que procesa la voz (Whisper) y genera las respuestas de la IA (LLaMA). Es gratuito para usar en proyectos como este.
1

Creá tu cuenta en Groq

Entrá a console.groq.com y registrate. Podés usar tu cuenta de Google.

💡 No necesitás tarjeta de crédito. El plan gratuito tiene un límite generoso — más que suficiente para este proyecto.
2

Generá tu API Key

Una vez dentro, andá a API Keys → Create API Key. Dale un nombre descriptivo como "GreenTech" y copiá la clave generada.

⚠️ Guardala en un lugar seguro — solo la podés ver una vez. Si la perdés, tenés que generar una nueva.
3

Guardá la key en la Raspberry Pi

Para que el script la encuentre automáticamente cada vez que arranca, la guardás como variable de entorno permanente:

bash
echo 'export GROQ_API_KEY="tu_clave_aqui"' >> ~/.bashrc
source ~/.bashrc

Verificá que quedó guardada:

bash
echo $GROQ_API_KEY

Tiene que mostrarte la clave. Si aparece, ya está configurada para siempre.

ℹ️ Una variable de entorno es como una variable global del sistema operativo. El script la lee con os.environ.get("GROQ_API_KEY") — así la clave nunca queda escrita en el código fuente.
4

Probá que el script arranca

bash
cd ~/greentech
python3 greentech_voz.py

Si ves el banner de GreenTech y el robot saluda por el parlante, todo está funcionando.

El script completo
El código completo del robot. Leélo de arriba hacia abajo — está organizado en bloques con comentarios que explican qué hace cada parte.
python · greentech_voz.py
# ── IMPORTACIONES ────────────────────────────────────────
import os, sys
from io import BytesIO
from groq import Groq
from gtts import gTTS
import pygame, time
import sounddevice as sd
import numpy as np
from scipy.io.wavfile import write as wav_write
import tempfile
from pydub import AudioSegment

# ── VERIFICACIÓN DE API KEY ───────────────────────────────
if not os.environ.get("GROQ_API_KEY"):
    print("❌ ERROR: Configurá la variable GROQ_API_KEY")
    sys.exit(1)

client = Groq()

# ── CONFIGURACIÓN ─────────────────────────────────────────
SAMPLE_RATE = 16000   # Hz óptimo para Whisper
DURACION_SEG = 5      # Segundos de grabación por turno

# ── FUNCIÓN: GRABAR AUDIO ─────────────────────────────────
def grabar_audio():
    print("\n🎙️  Hablá ahora... (grabando 5 segundos)")
    audio = sd.rec(
        int(DURACION_SEG * SAMPLE_RATE),
        samplerate=SAMPLE_RATE, channels=1, dtype='int16'
    )
    sd.wait()
    print("✅ Grabación finalizada.")
    tmp = tempfile.NamedTemporaryFile(suffix=".wav", delete=False)
    wav_write(tmp.name, SAMPLE_RATE, audio)
    return tmp.name

# ── FUNCIÓN: TRANSCRIBIR CON WHISPER ─────────────────────
def transcribir_audio(ruta_wav):
    with open(ruta_wav, "rb") as f:
        transcripcion = client.audio.transcriptions.create(
            model="whisper-large-v3", file=f, language="es"
        )
    os.unlink(ruta_wav)
    return transcripcion.text.strip()

# ── FUNCIÓN: HABLAR POR EL PARLANTE ──────────────────────
def hablar(texto):
    try:
        tts = gTTS(text=texto, lang='es')
        fp = BytesIO()
        tts.write_to_fp(fp)
        fp.seek(0)
        audio = AudioSegment.from_file(fp, format="mp3")
        audio_rapido = audio.speedup(playback_speed=1.3)
        fp2 = BytesIO()
        audio_rapido.export(fp2, format="mp3")
        fp2.seek(0)
        pygame.mixer.init()
        pygame.mixer.music.load(fp2)
        pygame.mixer.music.play()
        while pygame.mixer.music.get_busy():
            time.sleep(0.1)
        pygame.mixer.quit()
    except Exception as e:
        print(f"❌ Error al reproducir voz: {e}")

# ── FUNCIÓN: PREGUNTAR A LA IA ────────────────────────────
def preguntar_a_groq(pregunta, historial):
    print("\n[Pensando...]")
    historial.append({"role": "user", "content": pregunta})
    try:
        completion = client.chat.completions.create(
            model="llama-3.3-70b-versatile",
            messages=historial, temperature=0.7
        )
        respuesta = completion.choices[0].message.content
        historial.append({"role": "assistant", "content": respuesta})
        return respuesta
    except Exception as e:
        return f"Error: {e}"

# ── FLUJO PRINCIPAL ───────────────────────────────────────
if __name__ == "__main__":
    historial_chat = [{
        "role": "system",
        "content": (
            "Eres GreenTech, un robot asistente de reciclaje simpático y conciso. "
            "Respondés SIEMPRE en español. "
            "Cuando alguien te dice qué va a tirar, indicás si es RECICLABLE o NO RECICLABLE "
            "y en qué contenedor. Máximo 2 o 3 oraciones."
        )
    }]
    hablar("¡Hola! Soy GreenTech. ¿Qué vas a tirar hoy?")
    while True:
        try:
            ruta = grabar_audio()
            texto = transcribir_audio(ruta)
            if not texto: continue
            print(f"\nVos: {texto}")
            if any(p in texto.lower() for p in ["salir", "chau", "adiós"]):
                hablar("¡Hasta luego! Seguí reciclando.")
                break
            respuesta = preguntar_a_groq(texto, historial_chat)
            print(f"GreenTech: {respuesta}")
            hablar(respuesta)
        except KeyboardInterrupt:
            break
¿Qué hace cada función?
El script está dividido en cuatro funciones. Cada una tiene una responsabilidad clara. Hacé clic en cada una para ver los detalles.
grabar_audio() Captura tu voz por el micrófono ▼

Graba audio durante 5 segundos usando el micrófono del sistema. Guarda el audio en un archivo WAV temporal en el disco y devuelve la ruta de ese archivo.

¿Por qué WAV y no MP3? Whisper espera audio sin compresión. WAV es el formato crudo que el micrófono produce directamente.

variabletipodescripción
SAMPLE_RATEintFrecuencia de muestreo en Hz. 16000 es el valor que prefiere Whisper.
DURACION_SEGintCuántos segundos graba cada vez. Podés subir a 8 o 10 si el usuario habla despacio.
transcribir_audio(ruta_wav) Convierte voz a texto con Whisper ▼

Manda el archivo WAV a Whisper (el modelo de reconocimiento de voz de OpenAI, corriendo en los servidores de Groq) y recibe el texto transcripto. Después borra el archivo temporal para no llenar el disco.

¿Por qué Groq y no OpenAI directamente? Groq tiene hardware especializado (LPU) que hace que Whisper corra mucho más rápido que en los servidores de OpenAI, y además es gratuito.

parámetrovalordescripción
model"whisper-large-v3"La versión más precisa de Whisper. Reconoce bien el español rioplatense.
language"es"Forzar español mejora la precisión y la velocidad de transcripción.
hablar(texto) Convierte texto a voz y lo reproduce ▼

Recibe un string de texto, lo convierte a audio MP3 usando Google TTS (Text-to-Speech), acelera el audio con pydub, y lo reproduce por el parlante usando pygame. El proceso ocurre en memoria — no se guarda ningún archivo de audio.

¿Por qué acelerar el audio? gTTS genera una voz que suena un poco lenta. Con speedup(1.3) la llevamos a un ritmo más natural para una conversación.

parámetrovalor actualdescripción
lang'es'Idioma del TTS. Podés probar 'es-ar' para acento argentino.
playback_speed1.3Velocidad de reproducción. 1.0 = normal, 1.5 = bastante rápido.
preguntar_a_groq(pregunta, historial) Genera la respuesta de la IA ▼

Manda el texto del usuario junto con el historial completo de la conversación al modelo LLaMA 3.3. Recibe la respuesta y la agrega al historial antes de devolverla.

¿Por qué mandar el historial completo? Los modelos de lenguaje no tienen memoria propia entre llamadas. Al mandar toda la conversación anterior, el modelo puede entender el contexto — por eso puede recordar que antes te dijo que la botella era reciclable.

parámetrovalor actualdescripción
modelllama-3.3-70b-versatileModelo potente y rápido. Podés probar "llama-3.1-8b-instant" si querés más velocidad con menos precisión.
temperature0.7Controla la creatividad. 0 = respuestas exactas y repetibles. 1 = más variadas y creativas.

Ideas para extender el proyecto
Estas son extensiones reales que podés implementar. Están ordenadas por dificultad.
💡

LEDs de estado

Conectar LEDs al GPIO de la Raspberry: verde cuando escucha, azul mientras piensa, rojo si el ítem no es reciclable. Usás la librería RPi.GPIO.

fácil
📊

Registro de residuos

Guardar cada consulta en un archivo CSV o SQLite: qué tiró el usuario, si era reciclable, y la hora. Con eso podés generar estadísticas de uso.

fácil
🧠

Base de conocimiento local

Pasarle al robot un listado de materiales reciclables de tu municipio como parte del system prompt. Así las respuestas son específicas para Buenos Aires.

fácil
👁️

Detección por cámara

Usar la cámara de la Raspberry y un modelo de visión (YOLO o Google Vision API) para identificar el objeto automáticamente, sin que el usuario lo diga en voz alta.

avanzado
🔊

Voz más natural

Reemplazar gTTS por la API de texto a voz de Groq o ElevenLabs, que genera voces mucho más naturales y expresivas. Requiere otra API key.

medio
🚶

Detección de presencia

Usar el sensor HC-SR04 (ultrasonido) para detectar cuando alguien se acerca. El robot saluda solo cuando detecta una persona — sin que nadie lo active manualmente.

medio
💡 Para todas las extensiones el punto de partida es el mismo: el script que ya tenés funcionando. No hace falta reescribir nada — solo agregar funciones nuevas e integrarlas en el loop principal.
Arranque automático al encender
Para que el robot empiece a funcionar solo cuando conectás la Raspberry, sin necesidad de abrir una terminal ni correr ningún comando.
1

Creá el archivo de servicio

Systemd es el sistema que gestiona los servicios en Linux. Vas a crear un "servicio" que es básicamente una descripción de cómo y cuándo correr tu script.

bash
sudo nano /etc/systemd/system/greentech.service
2

Pegá este contenido

ini · greentech.service
[Unit]
Description=GreenTech Robot de Reciclaje
After=network.target

[Service]
ExecStart=/usr/bin/python3 /home/pi/greentech/greentech_voz.py
WorkingDirectory=/home/pi/greentech
Restart=on-failure
User=pi
Environment=GROQ_API_KEY="tu_clave_aqui"

[Install]
WantedBy=multi-user.target
⚠️ Reemplazá tu_clave_aqui con tu API Key real. Y si tu usuario no es pi, cambiá User=pi por tu usuario.
3

Activá el servicio

bash
sudo systemctl daemon-reload
sudo systemctl enable greentech
sudo systemctl start greentech
4

Verificá que está corriendo

bash
sudo systemctl status greentech

Si ves Active: active (running), el robot está corriendo. Si hay un error, el mismo comando te muestra los últimos logs para diagnosticar.
